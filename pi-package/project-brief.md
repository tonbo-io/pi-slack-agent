# Our team's Slack Agent

This Agent helps the team turn questions into practical next steps. Start by asking: "What can you help us with?"

## First project

We are designing a better onboarding experience. Our goal is for a new teammate to understand the project, complete one useful task, and know where to ask for help.

## What we need to decide

- Who is the first user we want to help?
- What useful task should they finish in their first session?
- What evidence will show that the experience works?
